# Приклади документів ДПС (знімок 2026-10-21)

ДПС публікує до «Опису АРІ Фіскального Сервера» архів «Приклади документів» —
XML чеків і Z-звітів із коментарями до кожного елемента. З `tax.gov.ua` його
взяти не вдалося: портал відповідає 403 і вбудованому браузеру, і `curl`
(сторінка, `data/files/*.docx`). Ті самі файли під тими самими назвами лежать у
відкритому проєкті `github.com/p2p-sys/OpenPRRO` (ліцензія MIT), каталог
`utils/examples/`, коміт `fbf0543aa64c83e2707ba8245a58a9a323317285` — звідти й
знято. Що з них випливає для нас — [../document-structures.md](../document-structures.md).

| Файл | Оригінальна назва | Що |
|---|---|---|
| `check01-all-elements.xml` | `check01(Опис всіх елементів).xml` | Чек з усіма елементами і коментарем до кожного: типи документа, формати полів, коди форм оплати, податків |
| `check01-goods.xml` | `check01(Товар).xml` | Продаж товарів, дві форми оплати, дві ставки |
| `check01-discounts.xml` | `check01(Знижки).xml` | Знижки на рядках: `COST` до знижки, `DISCOUNTSUM` окремо, `CHECKTAX` з `TURNOVER`/`SOURCESUM` |
| `check01-two-taxes.xml` | `check01(Два податки).xml` | ПДВ і акциз на одному рядку: база ПДВ без акцизу |
| `check01-return.xml` | `check01(Повернення).xml` | Видатковий чек: `DOCSUBTYPE 1`, `ORDERRETNUM` |
| `check01-service-deposit.xml` | `check01(Службове внесення).xml` | Службове внесення: лише `CHECKTOTAL.SUM` |
| `zrep01-all-elements.xml` | `zrep01(Опис всіх елементів).xml` | Z-звіт з усіма елементами і коментарями |

Що змінено при знятті: файли збережено в UTF-8, тому в рядку `<?xml …?>`
`encoding="windows-1251"` замінено на `encoding="UTF-8"`; у «Знижках» і «Двох
податках» частина рядків була двічі перекодована (cp1251 → latin-1 → UTF-8) —
їх відновлено. Більше нічого не правили, зокрема суперечності самих прикладів
(латинська `A` поруч із кириличною `Д` у `LETTER`, коди одиниць `25 кг` /
`87 бут`) — вони розібрані в `../document-structures.md`.

Інші приклади архіву (АЗС, валюта, ломбард, ПТКС, часткова сплата, офлайн-сесія)
нам не потрібні; за потреби — той самий каталог OpenPRRO.
