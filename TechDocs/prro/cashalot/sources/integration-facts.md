За https://portfel.ua/prro-api-cashalot/ (партнер, продає ліцензії): WEB API
«взаємодіє напряму з ФСКО», створює чеки і Z-звіти у XML, підписує КЕП,
рахує підсумки, автоматично створює Z-звіти, переходить в офлайн і назад із
реєстрацією офлайн-документів, підтримує файлові й апаратні ключі КЕП та
Smart ID; «великі компанії можуть розгорнути сервер АРІ ПРРО на власних
комп'ютерах». Доступ: після купівлі ліцензії — кабінет → реєстрація ГО, кас,
касирів; робота з WEB API «починається після активації коду доступу,
прив'язаного до фіскального номера каси». Стаття dtkt.ua (грудень 2021,
партнерська, https://news.dtkt.ua/debet-kredit/partner-news/73780-iak-integruvati-prro-cashalot-u-vasu-oblikovu-sistemu)
описувала локальний «API-сервер ПРРО» як окремий застосунок-вебсервіс на
стороні користувача для організацій від 100 кас, 500 грн/каса/рік — дата
стара, перевіряти в підтримці.

## Офлайн-режим (https://cashalot.ua/cashalot-offline)

«Ключі зберігаються локально», «Вся база у вас на пристрої» (це про РМК і
мобільний застосунок — для WEB API офлайн веде сервер Cashalot, див. спеку
«Автоматичне завершення режиму офлайн»); «До 36 годин поспіль або 168 годин
на місяць», «обмеження зняті на час воєнного стану»; після повернення зв'язку
чеки відправляються на сервер ДПС автоматично і отримують фіскальні номери;
«Інтерфейс не змінюється, лише додається індикатор офлайну»; інший пристрій
може відкрити зміну лише після завершення офлайн-сесії на першому і
синхронізації всіх чеків.

## Тестування проти ДПС

- Тестові документи — `TESTING=true` в `CHECKHEAD`/`ZREPHEAD`; їм призначаються
  фіскальні номери, але вони не фіскальні, у візуальній формі — «ТЕСТОВИЙ
  НЕФІСКАЛЬНИЙ ДОКУМЕНТ»; одна зміна містить або лише тестові, або лише
  фіскальні документи; `TESTING` заборонений для документів «Початок/Завершення
  офлайн сесії». Джерело — наш знімок [../../dps/fiscal-server-api.md](../../dps/fiscal-server-api.md),
  розділ «Тестові документи».
- Для роботи з API Фіскального Сервера потрібен **власний КЕП**; КНЕДП ІДД
  ДПС видає ключі безкоштовно; у ДПС є окремі тестові середовища API (адрес
  стаття не дає) — https://news.dtkt.ua/accounting/automation/73646-ci-potriben-ecp-dlia-testuvannia-prro-vid-dps
  (13.12.2021, стара), новина ДПС https://tax.gov.ua/nove-pro-podatki--novini-/537484.html.
- Cashalot WEB API сам ходить лише на продакшн-ФСКО (`fs.tax.gov.ua:8643`),
  тому «пісочниця» для нас — реальний ПРРО в кабінеті + тестові документи.

## Доступ до WEB API (зі спеки, розділи «Необхідні доступи» / «Перед початком роботи»)

1. Кабінет https://my.cashalot.org.ua — зареєструватись, зареєструвати
   суб'єкта господарювання, господарські одиниці (ГО), каси (ПРРО), касирів.
2. У списку кас завантажити і зберегти ліцензії ПРРО.
3. TLS 1.2/1.3; запити — `https://fsapi.cashalot.org.ua/`.
4. «Налаштування → Інтеграція з WEB API → Управління касирами» — там `KeyGuid`
   і PIN касира, якщо ключ лишається в Cashalot, а не передається в кожному
   запиті.
